# data/boundaries/

Ward boundary maps used to find which ward each hotspot is in (`tools/ward_lookup.py`).

| File | What it shows | Source | Notes |
| --- | --- | --- | --- |
| `pmc-electoral-wards-2025.kml` | 41 PMC electoral wards (prabhags) for the 2026 election. Ward number is in the `qwr` field. | [OpenCity – PMC Wards Info](https://data.opencity.in/dataset/pune-wards-info), "PMC Electoral Wards 2025" | Decides the 4 corporators for a hotspot |
| `pmc-electoral-wards-2025-labelled.kml` | Same 41 wards, each named "Prabhag N" for clean labels in Google My Maps | Made from the file above | Use this one on the team map |
| `pmc-admin-wards-2017.kml` | 15 PMC administrative wards (ward offices) as of 2017 | Same dataset, "Pune Administrative Wards Map 2017" | Out of date for merged villages: Keshavnagar is not covered, and Mundhwa shows under Dhole Patil Road. Confirm the ward office by phone. |

Downloaded 8 Oct 2026. OpenCity lists these as sourced from PMC.
