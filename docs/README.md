# docs/

- `architecture.md` – how the repo fits together: folder map, data flow, where each planned feature plugs in
- `adding-features.md` – recipes: a new area, a translation, a page, a feature, a hotspot type, a sheet tab
- `data-model.md` – every data file, its columns and the rules the export script checks
- `phase-4.md` – photo reports from residents: decisions, how a report travels, technology, data, limits, privacy, milestones
- `proposal.pdf` – signed project proposal (add after signatures)
- `meeting-notes/` – one file per weekly meeting, named `YYYY-MM-DD.md` (copy `TEMPLATE.md`)
- `starter-tasks.md` – first cards for the project board
